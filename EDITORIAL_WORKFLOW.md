# EDITORIAL_WORKFLOW

## Partial

Admin UI підтримує локальні CRUD-операції в пам’яті та кнопки переходів `under_review`, `published`, `rejected`. Це демонстрація інтерфейсу, не захищений редакційний процес.

## Planned

1. Editor створює draft джерела та окрему version.
2. Система зберігає оригінал, hash і fragments.
3. Editor звіряє fragment з оригіналом та створює citation.
4. Reviewer перевіряє точність, чинність і застосовність.
5. Server-side RPC валідовує reviewer/time та публікує транзакційно.
6. Зміна джерела створює нову version і переводить залежні матеріали у `needs_review`.
7. Критичні зміни потрапляють до незмінного `audit_log`.

## Blocked

Публікація реального корпусу заблокована до призначення юридичного редактора. Домедичні матеріали додатково потребують медичного рецензента. Поточні кнопки admin не є доказом виконання workflow.
