# DESIGN_SYSTEM.md — Дизайн-система и доступность (A11y)

## 1. Цветовая палитра и темы

Приложение использует Tailwind CSS 4 с полной поддержкой двух тем оформления:
- **Светлая тема (Light Mode)**: базовая палитра Slate-50/White, глубокие сине-индиговые акценты (Indigo-600, Sky-600).
- **Тёмная тема (Dark Mode)**: глубокая палитра Slate-900/950 с контрастным текстом Slate-100/200.

Переключение темы производится через `ThemeProvider` и фиксируется в классах документа `document.documentElement`.

## 2. Атомарные UI Компоненты (`src/shared/ui`)

1. **Button**:
   - Варианты: `primary`, `secondary`, `outline`, `ghost`, `danger`.
   - Поддержка размеров: `sm`, `md`, `lg`.
   - Минимальный габарит кликабельной области: 44×44px.

2. **Combobox** (`Combobox.tsx`):
   - Реализация спецификации WAI-ARIA Combobox Pattern.
   - Фильтрация параметров при вводе.
   - Навигация с клавиатуры: `ArrowUp`, `ArrowDown`, `Enter`, `Escape`.
   - Атрибуты: `role="combobox"`, `role="listbox"`, `role="option"`, `aria-expanded`, `aria-activedescendant`.

3. **Drawer** (`Drawer.tsx`):
   - Мобильная выкатная панель навигации.
   - Закрытие по Escape и клику вне области.
   - Захват фокуса и блокировка прокрутки фона.
   - Атрибуты: `role="dialog"`, `aria-modal="true"`.

4. **Modal** (`Modal.tsx`):
   - Доступный диалог для просмотра контекста цитат и отчетов об ошибках.
   - Поддержка закрытия с клавиатуры и фокусировка.

5. **CitationCard** (`CitationCard.tsx`):
   - Карточка для выделенного отображения нормативной цитаты с указанием источника, редакторского статуса и даты проверки.

6. **Skeleton** (`Skeleton.tsx`):
   - Индикатор загрузки в виде заполнителей с анимацией плавной пульсации.

---

## 3. Требования доступности (A11y)

- **Интерактивные элементы**: минимальный размер сенсорной зоны — 44×44px.
- **Поддержка скринридеров**: наличие `<h1>` на всех ключевых страницах, использование `<label>` и `aria-label` для всех полей ввода.
- **Анимации**: поддержка медиа-запроса `prefers-reduced-motion` в `index.css` для отключения резких анимаций при соответствующих настройках ОС.
