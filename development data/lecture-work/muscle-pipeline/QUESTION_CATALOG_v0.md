# QUESTION_CATALOG v0 — расширяемый список вопросов читателя

Каталог **не закрытый**. Новые формулировки добавляются как `Q-NEW-…` или через `proposed_question` в placement-строке, затем при approve вносятся сюда стабильным id.

Формат id: `Q-{domain}-{nnn}` где domain — короткий код предметной области.

Вопрос пишется **с точки зрения читателя** (що зробити / коли потрібно / хто відповідає / які документи), украинский язык — как в UI.

## Як расширять

1. Если `proposed_question` повторяется ≥2 раза в placements — выдать стабильный `Q-…` id и дописать сюда.
2. Не сливать разные вопросы читателя в один ради «красоты» списка.
3. Почти-одинаковые вопросы на **разных** карточках (в т.ч. в одном разделе) — допустимы и часто желательны.
4. Новый вопрос ≠ сразу новая карточка в сайте: insert новой ситуации только при накоплении **> 2000** символов текста (см. SCHEMA).
5. Версия: при крупном пересмотре — `QUESTION_CATALOG_v1.md`, v0 не удалять без запроса.
