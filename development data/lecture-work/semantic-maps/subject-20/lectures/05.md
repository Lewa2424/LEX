# Блок 5. Виробничі джерела запалювання

Займання можливе за одночасної наявності горючого середовища та достатнього джерела запалювання. У виробництві такими джерелами можуть бути відкритий вогонь, нагріті поверхні, іскри, електрична енергія, механічне тертя, хімічні реакції, самонагрівання й статична електрика. Захист усуває або контролює хоча б одну з необхідних умов горіння.
