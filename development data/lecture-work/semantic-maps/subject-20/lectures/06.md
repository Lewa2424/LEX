# Блок 6. Обмеження розвитку аварій і пожежі

Поширення аварії стримують обмеженням кількості горючих речовин, локалізацією витоку/розливу, аварійним відключенням, захисною арматурою, відсіканням поширення та підготовленими планами реагування. Конкретні системи мають проєктуватися для конкретного процесу; самостійне керування аварійною арматурою непідготовленою особою небезпечне.
