# Додаткові джерела предмета 13

## Правило читання

Це семантична карта PDF-матеріалів предмета, а не дублювання їхнього тексту. Для нормативного документа карта вказує, **де шукати правило**, а не замінює норму переказом. Таблиці, строки, числові межі, форми документів та галузеві процедури мають братися з точного пункту або сторінки першоджерела перед підготовкою відповіді.

## Внутрішні пріоритети під час наповнення

1. Для загальної процедури — спочатку закон, наказ або ДБН з таблиці вище.
2. Для зрозумілого пояснення — лекція або практична робота предмета.
3. Для шахти, металургії, вантажопідіймальних машин чи промислової залізниці — спочатку перевірити, що ситуація справді належить до цієї сфери.
4. Для першої допомоги — не редагувати алгоритм «за пам'яттю»: окремо звіряти потрібний порядок Наказу МОЗ № 441.
