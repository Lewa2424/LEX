# Семантический корпус LEX

## Назначение

Это внутренний навигационный корпус для наполнения LEX материалами лекций. Он не является пользовательским справочником и не подменяет первоисточники, нормативные акты или утверждённые инструкции предприятия.

## Как читать корпус

1. `INDEX.md` предмета — входная точка и перечень тематических карт.
2. `lectures/*.md` — смысловые карты материала.
3. `SUBJECT-MATRIX.md` — связи предмета с крупными разделами LEX.
4. Карта **доказательного уровня** содержит конкретные слайды/страницы, ограничения и, где доступно, ссылку на извлечение.
5. **Навигационная карта** описывает тему и её источник, но перед созданием ответа требует точечного извлечения нужного фрагмента.

## Правило перехода к ответу

Готовый ответ для сайта можно строить только по доказательной карте либо после доработки навигационной карты: `ситуация → источник → страница/слайд → смысловой фрагмент → ответ`.

## Реестр готовности предметов

| Уровень | Предметы | Что доступно сейчас |
|---|---|---|
| Доказательный | 12–17 | Детальные смысловые блоки с привязкой к слайдам/страницам и ограничениями источника. |
| Переходный | 7 | Содержательные карты с источниками и пределами применения; для большинства будущих ситуаций достаточно точечно сверить первичный материал. |
| Навигационный | 1–6, 8–11, 18–21 | Темы, крупная маршрутизация и лекция-источник определены; для готового ответа сначала извлекается конкретный фрагмент. |

Это не оценка качества предмета. Уровень показывает только плотность первичной привязки, необходимую для безопасного создания ответа.

## Служебные файлы

Файлы с именами `*-working.md` и `*-comparison.md` являются рабочими заметками или сравнением версий. Они не являются самостоятельными лекционными картами и не участвуют в подборе материала для ответа.

Детальный формат описан в [стандарте карт](CARD-STANDARD.md), а допустимые маршруты — в [словаре тегов](TAG-DICTIONARY.md).
