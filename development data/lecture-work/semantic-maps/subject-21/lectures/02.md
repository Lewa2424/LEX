# Блок 2. Експертиза промислової безпеки

Промислова експертиза оцінює відповідність об'єкта, процесу або документації встановленим вимогам у межах доручення. Для висновку потрібні компетентна комісія, перевірка вихідних даних, огляд, аналіз, документування результатів і належне оформлення.

**Для LEX:** `safety_management`, `equipment_systems`, `audit_improvement`.

**Джерела:** `Лекц 2 (Експ).pdf`; `Презентац л2 (Ек).pdf`.

**Межа:** порядок комісії та форми висновків звіряються за чинними вимогами.
