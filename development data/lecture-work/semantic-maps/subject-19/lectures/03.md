# Блок 3. Оцінювання професійного ризику

Оцінювання може бути якісним, напівкількісним або кількісним. Метод добирають за складністю системи, наслідками, даними та метою рішення. Ймовірність, тяжкість, експозиція й наявні бар'єри треба описувати явно; число з матриці саме по собі не є об'єктивною «величиною небезпеки».

**Для LEX:** `hazards_risks`, `safety_management`.

**Джерела:** `Ризик лекція 4.pptx`, слайди 1–36; `iso_31010.docx`.

**Межа:** не створювати на сайті універсальний калькулятор ризику без методики, даних і правил інтерпретації.
