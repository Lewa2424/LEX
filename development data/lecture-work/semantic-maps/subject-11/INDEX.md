# Карта предмета 11: виробниче середовище та професійні захворювання

## Призначення

Внутрішня карта матеріалів для LEX про шкідливі виробничі фактори та профілактику професійних захворювань. Вона не використовується для встановлення діагнозу, причинного зв'язку конкретного захворювання з роботою чи лікувальних рекомендацій.

## Склад і відбір

Архів містить лекції, презентації, накази, практичні завдання, літературу й сторонню контрольну роботу. Для карт використано лекційні та нормативно-методичні матеріали; персональна контрольна робота, літературний список і технічні завдання не є джерелом змісту для LEX.

## Робочі правила

1. Відповідь у LEX описує фактор, шлях профілактики та необхідність фахової оцінки — не симптоми як самодіагностику.
2. Переліки професійних захворювань, МСЕК/експертиза, гігієнічні класи й накази звіряються з чинним правом.
3. Для підозри на професійне захворювання не можна обмежитися усуненням фактора: потрібні медичні й процедурні дії у встановленому порядку.
