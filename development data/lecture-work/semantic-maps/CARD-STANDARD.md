# Стандарт семантической карты LEX

## Обязательный минимум

Каждая карта должна содержать:

1. Заголовок, точно описывающий тему.
2. Смысловое ядро: что материал объясняет и при каких границах применим.
3. Маршрут к одному или нескольким разделам LEX.
4. Источник: имя файла и, если известно, диапазон страниц или слайдов.
5. Ограничения: что нельзя переносить в готовый ответ без проверки.

## Уровни готовности

### Доказательная карта

Содержит тему, точные страницы/слайды, смысловые блоки, ограничения и при возможности ссылку на первичное извлечение. Её можно использовать для построения ответа после проверки актуальности нормативной части.

### Навигационная карта

Содержит тему, крупный смысловой вывод, маршрут LEX и лекцию-источник. Она пригодна для отбора нужного материала, но до создания ответа требует точечного извлечения фрагмента из лекции.

## Нормализация маршрутов

В `Для LEX` и в матрицах используют идентификаторы действующих крупных разделов сайта из `TAG-DICTIONARY.md`. Запись вида `section-id-number` допустима только как внутренний временный ключ будущей ситуации внутри известного крупного раздела; это не ID текущего интерфейса и не самостоятельный раздел. Уточняющие ситуации без такого ключа записываются обычным текстом после идентификатора. Новые незафиксированные технические теги не создавать.

## Не включать в будущий ответ без проверки

- числовые нормативы, сроки, классы и формулы;
- реквизиты нормативных актов;
- алгоритмы для аварий, медицины, эвакуации и опасных работ;
- проектные или технологические решения для конкретного объекта.
