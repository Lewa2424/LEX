# Тема 8. Ергономічна оцінка виробничого завдання

## Про що матеріал

Матеріал показує, як перетворити спостереження за конкретною операцією на оцінку ергономічного ризику та обґрунтований вибір технічних чи організаційних заходів.

## Смислові блоки

- Перед оцінюванням описують завдання, працівника, позу, зусилля, тривалість, повторюваність, вантаж, інструмент і умови середовища.
- Згадані методи REBA, RULA, Strain Index, NIOSH, MAC та чек-листи мають різні сфери застосування: не можна механічно підміняти один метод іншим або переносити бал без умов спостереження.
- Результат оцінки використовують для пошуку змін у технології, пристроях, висоті/розміщенні, способі захвату, механізації, розподілі роботи чи тривалості операції.
- Приклад автосервісу демонструє логіку «виміряти — змінити процес/оснащення — повторно оцінити», а не готове рішення для будь-якого робочого місця.

## Для майбутніх відповідей

- `ergonomics_human_factor`: як провести первинну оцінку пози й ручного навантаження.
- `hazards_risks`: добір методу оцінювання та перевірка ефективності заходів.
- `technology_processes`: механізація й зміна технологічного процесу для зниження навантаження.
