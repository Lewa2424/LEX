# Тема 4. Прогнозування небезпечних впливів НС

## Смислові блоки

- Прогнозування зменшує невизначеність: воно дає змогу оцінити можливий розвиток події, зони впливу, потребу в силах і захисних заходах.
- Для хімічних, радіаційних і пожежних сценаріїв використовують різні моделі, вихідні дані та припущення; результат не можна переносити між типами НС.
- Розрахунки залежать від фактичних умов, параметрів джерела, метеоданих, рельєфу, часу та стану захисних систем.
- Прогноз — основа для рішення, але потребує оновлення за даними фактичної обстановки.

## Для LEX

- `emergencies`: роль прогнозу та необхідні вхідні дані для оцінки наслідків.
- `civil_radiation_chemical`: загальні принципи оцінювання хімічної та радіаційної обстановки.
- `fire_explosion`: сценарії поширення пожежі як окрема частина прогнозування.
