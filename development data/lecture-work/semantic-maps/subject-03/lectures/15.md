# Блок 15. Невідкладні стани

Шок, важка алергічна реакція, інсульт, інфаркт, діабетичні стани, судоми, гіпер- та гіпотермія можуть бути загрозливими для життя. Навчальний матеріал потрібний для розпізнання тривожних ознак і розуміння терміновості, а не для встановлення діагнозу. У відповідях LEX цей блок має вести до виклику екстреної допомоги та дій у межах домедичної підготовки.

**Для LEX:** `first_aid`, `occupational_health`, `emergencies`.

**Джерело:** `Конспект лекції 15.pdf`, с. 1–24.
