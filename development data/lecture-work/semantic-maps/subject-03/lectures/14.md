# Блок 14. Опіки, електротравми та відмороження

Опіки, електротравми й відмороження відрізняються механізмом ураження та небезпечними ускладненнями. Для домедичної допомоги спільним є усунення чинника лише за безпечних умов, оцінка життєвих функцій, виклик допомоги та недопущення додаткового ушкодження. Особливо при електротравмі небезпека для рятувальника не менш важлива, ніж стан потерпілого.
