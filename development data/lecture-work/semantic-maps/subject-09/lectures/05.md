# Блок 5. Освітлення гірничих виробок

Освітлення забезпечує орієнтацію, видимість небезпек, безпечну роботу й евакуацію. Для виробок важливі тип, розміщення, стан світильників, надійність живлення, усунення засліплення та індивідуальні світильники у визначених умовах.
