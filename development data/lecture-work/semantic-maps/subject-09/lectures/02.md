# Блок 2. Вимоги до персоналу шахт

Для робіт, від яких залежить безпека багатьох людей, потрібні компетентність, підготовка, перевірка знань, визначені повноваження та придатність у межах чинних процедур. Організація безпеки не повинна триматися на одній посаді або формальному навчанні.

**Для LEX:** `worker_admission`, `safety_management`, `high_risk_work`.

**Джерела:** `Лекція №2.docx`; `Лекція №3.docx` (дубль).

**Межа:** посадові вимоги й порядок перевірок у лекції можуть бути застарілими.
