# Матриця зв'язків: предмет 7 → LEX

| Карта LEX | Що дає предмет |
|---|---|
| `protective_equipment` | Вибір, використання, догляд і межі всіх основних видів ЗІЗ |
| `work_environment` | Вихідні дані для добору: пил, гази, шум, температура, випромінювання |
| `high_risk_work` | Висота, електроустановки, аварійні та замкнені простори |
| `fire_explosion` | Термоодяг, ЗІЗОД, рукавички й обмеження застосування у пожежонебезпечних роботах |
| `civil_radiation_chemical` | ЗІЗ у хімічних і радіаційних НС |
| `ergonomics_human_factor` | Сумісність, рухливість, теплове навантаження і припасування |
| `safety_management` | Програма управління, облік, навчання та перевірка результативності |
| `documents_records` | Стандарти, маркування, документація та статус придатності |

## Головна вказівка для майбутніх відповідей

ЗІЗ формулюється як частина системи контролю ризику. Відповідь спочатку називає, що слід усунути або контролювати в джерелі, а потім — який клас/тип захисту може бути потрібний і що треба перевірити перед його використанням.
