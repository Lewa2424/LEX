# Блок 2. Фільтрувальні ЗІЗ органів дихання

Фільтрувальні ЗІЗОД захищають лише в межах свого типу, класу й умов застосування. Для вибору необхідно знати агрегатний стан і властивості забруднювача (аерозоль, газ, пара, комбінований фактор), його концентрацію, вміст кисню, тривалість роботи, фізичне навантаження та сумісність з іншими ЗІЗ.

Ключові елементи надійності: щільне прилягання, справні клапани/фільтри, правильне зберігання, контроль строку придатності, заміна фільтра за встановленою програмою та навчання користувача. Борода, пошкодження обтюратора чи неправильний розмір можуть звести захист нанівець.

## Для майбутніх відповідей

- `protective_equipment`: добір фільтрувального ЗІЗОД і його обмеження.
- `work_environment`: пил, аерозолі, гази й пари як вихідні дані для добору.
- `emergencies`: ситуації, де фільтрувальний засіб не слід вважати рішенням за замовчуванням.
