# Блок 8. Дерматологічні засоби

Захисні креми, очищувальні та репаративні засоби можуть зменшувати контакт шкіри з окремими забруднювачами й підтримувати догляд за шкірою, але не замінюють рукавички, технологічний захист, вентиляцію чи гігієну. Вибір пов'язаний із конкретною речовиною, частотою контакту, станом шкіри й сумісністю з іншими ЗІЗ.

## Для майбутніх відповідей

- `protective_equipment`: дерматологічні ЗІЗ як додатковий шар.
- `occupational_health`: профілактика шкірного контакту без медичної діагностики.

## Джерела й межі

- Основне: `Лекція 11.pdf`, с. 1–18.
- Практичне доповнення: `Практика 11.pdf`.
- Не рекомендувати лікувальні засоби або інтерпретувати шкірні симптоми без медичного фахівця.
