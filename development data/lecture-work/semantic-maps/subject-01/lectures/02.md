# Блок 2. Підготовка металургійної сировини

Підготовка сировини включає збагачення, подрібнення, класифікацію та окускування матеріалів для подальшої плавки. Устаткування може використовувати гравітаційне, магнітне, флотаційне та інші способи розділення. Для безпеки важливо розглядати не «руду» загалом, а конкретні операції з пилом, рухомими механізмами, транспортом, дробленням, грануляцією чи спіканням.

**Для LEX:** `technology_processes`, `equipment_systems`, `work_environment`, `hazards_risks`.

**Джерела:** `Л2_...pptx`; лабораторні матеріали з окускованої сировини.
