# Порівняння лекцій 12 і 13

## Результат

Лекції мають один змістовий масив: наряд-допуск, галузеве положення для металургії та ГЗК, акт-допуск і форми документів. Лекція 13 не доповнює карту новими правилами.

| Перевірка | Результат |
| --- | --- |
| Тема, структура, нотатки | тотожні |
| Форми та вбудовані зображення | тотожні |
| Новий нормативний матеріал | не виявлено |
| Дубль усередині версії 13 | слайд 20 = 19; слайди 64 і 65 = фінальний слайд лекції 12 |
| Базове джерело для матриці | лекція 12 |

## Наслідок для матриці

Обидва файли враховані як прочитані. Для доказової прив’язки використовуються слайди лекції 12; лекція 13 потрібна лише для контролю повноти витягу.
