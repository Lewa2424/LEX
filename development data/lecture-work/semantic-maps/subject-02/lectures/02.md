# Блок 2. Природні ресурси, біорізноманіття й антропогенний вплив

Природні ресурси є компонентами довкілля, необхідними для життєдіяльності та господарства. Антропогенний вплив може змінювати екосистеми, ландшафти та біорізноманіття, тому охорона довкілля охоплює не тільки усунення видимих забруднень, а й збереження та відновлення середовища.
