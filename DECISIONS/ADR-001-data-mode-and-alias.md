# ADR-001: Data mode та alias

**Статус:** Accepted for scaffolding  
**Дата:** 2026-08-09

## Рішення

- `VITE_DATA_MODE=mock | supabase` є єдиною точкою вибору адаптерів.
- `mock` залишається безпечним режимом за замовчуванням.
- `supabase` без public URL/anon key не створює клієнт; repositories повертають явний `NOT_CONFIGURED`.
- Alias `@` поки вказує на корінь проєкту. Його не змінюємо під час scaffolding, щоб не створювати масову міграцію імпортів.

## Наслідки

Mock UI працює без мережі. Реальний режим навмисно неповний і не маскує відсутню конфігурацію. Майбутня зміна alias на `src` потребуватиме окремого ADR та атомарного оновлення imports/config/tests.
